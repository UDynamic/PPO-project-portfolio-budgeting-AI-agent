%  ABSTRACT
% ============================================================

\begin{abstract}

  Allocating a shared capital reserve across a portfolio of simultaneously
  executing contracted projects is a high-frequency, high-stakes decision for
  engineering contractors.  Classical approaches either assume full foresight or
  collapse the portfolio to a single project, leaving practitioners with no
  principled tool for the sequential, multi-project setting under real-world
  uncertainty.  This paper closes that gap by delivering a complete, verified
  simulation environment that makes the problem tractable for data-driven methods.
  
  We formalise the problem as a Constrained Markov Decision Process in which a
  portfolio manager allocates budget fractions across $N$ concurrent projects at
  each discrete period.  The state encodes Earned Value Management indicators,
  S-curve planned progress, milestone payment lookaheads, and a per-project
  breach-tolerance counter.  The transition dynamics reproduce the full FIDIC
  contract cash-flow cycle: advance payment and recovery, progress-weighted
  milestone gross payments, retention withholding and release, interest charges
  on treasury draws, and a two-condition termination gate.  The reward signal is
  the $\gamma$-discounted portfolio net cash flow, accumulating to an episode NPV
  that serves as the primary performance criterion.
  
  The environment is released as a configurable, Gymnasium-compatible package
  with a SQLite audit ledger that records every allocation, cash-flow event, and
  breach flag --- eliminating the black-box problem inherent to learned policies.
  To establish a performance baseline and motivate the need for learned agents,
  we run three deterministic greedy heuristics (Reach-Plan, Catchup-T, and
  Catchup-Next-T) and a manually computed full-information optimum across four
  benchmark configurations of increasing portfolio complexity.  The results show
  a systematic and widening gap between the greedy baselines and the optimal
  solution as portfolio complexity grows, confirming that standard rule-based
  allocation is insufficient and that a well-defined improvement target exists
  for reinforcement learning agents.  Training such agents and evaluating them
  against a formal Linear Programming bound are identified as the natural next
  steps, addressed in subsequent work.
  
  \medskip
  \noindent\textbf{Keywords:} project portfolio management; budget allocation
  under performance uncertainty; constrained Markov decision process;
  reinforcement learning; FIDIC contracts; earned value management;
  Gymnasium environment; greedy baseline; optimality gap.
  
  \end{abstract}
