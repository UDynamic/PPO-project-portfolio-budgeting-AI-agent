\section{Introduction}

Artificial intelligence systems have advanced rapidly in recent years.

Recent work such as \cite{vaswani2017attention} introduced architectures
that significantly improved sequence modeling tasks.

In this work we investigate methods for improving project portfolio
optimization using reinforcement learning.

\subsection{Motivation}

Efficient resource allocation is critical in large-scale projects.

\subsection{Contributions}

The contributions of this paper are:

\begin{itemize}
\item A reinforcement learning framework for project portfolio optimization
\item A simulation environment for portfolio budgeting
\item Empirical evaluation of PPO-based agents
\end{itemize}
